# Демо к лекции «Полиморфизм в C++: как это устроено внутри»

Нужны g++ (проверено на 13.3) и clang++ (проверено на 18.1; нужен только для дампов раскладки и vtable). Linux или WSL.

```
git clone https://github.com/Nikita4gj/polymorphism-demos.git # клонировать репозиторий
cd polymorphism-demos
./run_all.sh        # все демо подряд
./run_all.sh 07     # одно демо: номер стоит в правом нижнем углу слайда
```
